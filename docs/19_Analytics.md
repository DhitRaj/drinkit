# 19. Analytics

This is the product-facing analytics index. The detailed KPI plan lives in [docs/20_Analytics_KPIs.md](docs/20_Analytics_KPIs.md).

## Measurement Areas

- Acquisition
- Activation
- Retention
- Monetization
- Marketplace health
- Compliance

## Rules

- Server events are the source of truth for money and order state.
- PII must not enter analytics payloads.
- Compliance metrics are guardrails, not optional dashboards.
