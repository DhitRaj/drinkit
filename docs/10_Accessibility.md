# 10. Accessibility

## 1. Baseline

- All interactive elements need accessible labels.
- Touch targets must remain comfortably tappable on mobile.
- Text must remain legible under large font settings.
- Color must never be the only way to convey status.

## 2. Priority Cases

- OTP input.
- Age verification screens.
- Checkout and payment flows.
- Error states and retry actions.

## 3. Practical Rules

- Keep essential copy short enough to scale.
- Preserve focus order in forms and bottom sheets.
- Provide clear status text for live tracking and payment updates.
