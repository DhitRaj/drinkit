# 18. Search

## 1. Search Objectives

- Help users find brands and categories quickly.
- Support typo-tolerant search and filters.
- Surface in-stock and serviceable items first.

## 2. Search Surfaces

- Home search bar.
- Category result pages.
- Search results with sort and filter.
- Reorder and recommendation entry points.

## 3. Rules

- Search should respect location and compliance constraints.
- Out-of-stock items can remain visible if policy allows, but must be clearly labeled.
- Search analytics should track zero-result and conversion behavior.
