# 07. Design System Index

The source of truth for the visual system is [docs/design/06_Design_System.md](docs/design/06_Design_System.md).

## Scope

- Dark premium visual language.
- Gold as the single brand accent.
- Strong token discipline for color, spacing, typography, and motion.
- Mobile-first rules for customer and delivery apps.

## Use Rules

- Never introduce raw hex colors in product screens.
- Never break the 4 pt spacing grid.
- Never use icons, buttons, or text treatments that conflict with the approved system.
